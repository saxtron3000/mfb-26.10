## **Chapter 3: Monetary Systems — Fiat vs. Sound Money**

| Aspect | Sound Money ([Gold](https://programs.myfirstbitcoin.org/lexicon/en/#gold)/Commodity) | [Fiat Money](https://programs.myfirstbitcoin.org/lexicon/en/#fiat-money) (Government Decree) |
|--------|------------------------------|--------------------------------|
| **Backing** | Physical commodity (gold, silver) | Government decree + trust      |
| **Supply** | Limited by [scarcity](https://programs.myfirstbitcoin.org/lexicon/en/#scarcity) of commodity | Unlimited; can be printed      |
| **[Inflation](https://programs.myfirstbitcoin.org/lexicon/en/#inflation)** | Low (commodity supply grows slowly) | High (governments print more)  |
| **Who controls?** | Market determines [value](https://programs.myfirstbitcoin.org/lexicon/en/#value); no single authority | [Central bank](https://programs.myfirstbitcoin.org/lexicon/en/#central-bank) + government      |
| **[Purchasing power](https://programs.myfirstbitcoin.org/lexicon/en/#purchasing-power)** | Relatively stable over decades | Erodes over time               |
| **Can be debased?** | Difficult (commodity is commodity) | Easy (print more, reduce value per unit) |
| **Security** | Based on physical scarcity   | Based on trust in authority    |

## **Chapter 7: On-Chain vs. Lightning Network**

| Feature | On-Chain Bitcoin | Lightning Network |
|---------|------------------|-------------------|
| **Speed** | \~10 minutes     | Seconds           |
| **Cost** | $1–30            | <$0.01            |
| **Finality** | Permanent after 6 confirmations | Instant; settles on-chain later |
| **Best for** | Large transfers; settlements | Micropayments; daily spending |
| **Scalability** | 7 tx/sec on-chain | Millions tx/sec possible |
| **Security** | [Blockchain](https://programs.myfirstbitcoin.org/lexicon/en/#blockchain) security | Bitcoin blockchain backing |
| **[Privacy](https://programs.myfirstbitcoin.org/lexicon/en/#privacy)** | Pseudonymous; public record | Better privacy (channels off-chain) |

## **Chapter 9: Mining Economics — Incentive Structure**

### **Miner Revenue**

```
[Block Reward](https://programs.myfirstbitcoin.org/lexicon/en/#block-reward) (fixed) = 6.25 BTC (halves every 4 years)
Transaction Fees (variable) = Sum of fees in block
Total Revenue = 6.25 BTC + Fees
```

### **Miner Costs**

```
Hardware: $5,000–$100,000+ (amortized over years)
Electricity: $0.02–0.05 per kWh (varies by region)
Cooling: Significant for large operations
Pool Fees: 1-2% of earnings (if in [mining pool](https://programs.myfirstbitcoin.org/lexicon/en/#mining-pool))
```

### **Incentive Alignment**

* If Bitcoin [price](https://programs.myfirstbitcoin.org/lexicon/en/#price) is high → mining profitable → more miners join → difficulty increases → less profitable until price goes up or miners exit
* Boom-bust cycle naturally regulates participation
* Security cost = electricity spent; makes [51% attack](https://programs.myfirstbitcoin.org/lexicon/en/#51-attack) exponentially expensive

## **Chapter 10: CBDC vs. Bitcoin — Fundamental Differences**

| Aspect | CBDC (Government Digital [Currency](https://programs.myfirstbitcoin.org/lexicon/en/#currency)) | Bitcoin |
|--------|------------------------------------|---------|
| **[Issuer](https://programs.myfirstbitcoin.org/lexicon/en/#issuer)** | Central bank                       | Decentralized network (no issuer) |
| **Supply** | Unlimited; government controls     | Fixed 21 million; algorithm controls |
| **Control** | Government can freeze accounts, reverse transactions | No authority can stop transactions |
| **Privacy** | Government can see all transactions | Pseudonymous; transparent on chain |
| **Accessibility** | Requires central bank system; can exclude | Anyone with internet can participate |
| **Programmable** | Yes; government sets rules         | Limited; network [consensus](https://programs.myfirstbitcoin.org/lexicon/en/#consensus) required |
| **Censorship Risk** | High; government can freeze/block  | Low; decentralized consensus |
| **Financial [Sovereignty](https://programs.myfirstbitcoin.org/lexicon/en/#sovereignty)** | False (you use government's system) | True (you control your money) |
