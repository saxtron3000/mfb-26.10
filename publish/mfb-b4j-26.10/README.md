# Bitcoin for Juniors Review Workspace

This repository is a working space for reviewing and improving the *Bitcoin for Juniors* educational program for the October 2026 version.

The goal is to make the program clearer, more practical, easier to teach, and more engaging for younger learners.

## What Is Here

- `workspace/` - Planning notes, review scope, tasks, drafts, and program specs.
- `ref/bitcoin-for-juniors/en/` - Reference copy of the current English curriculum.
- `feedback/` - Feedback and review notes from collaborators.

## Current Focus

The review is focused on:

- improving lesson clarity, flow, and age fit,
- tightening repeated or overlapping lesson sections,
- strengthening activities with clearer objectives, timing, materials, and facilitator guidance,
- adding practical classroom options, including low-prep and differentiated activities,
- reviewing supporting materials such as parent guides, forewords, and teacher-facing notes.
