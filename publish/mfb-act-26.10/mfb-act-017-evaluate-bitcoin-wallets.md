# Evaluate Bitcoin Wallets
## Keywords
Bitcoin wallets, wallet selection, research
## Activity Type
Class discussion and research
## Participation

## Duration

## Description
Students research Bitcoin wallets, compare trade-offs using consistent criteria, and explain which option may fit a stated learner need without creating a global recommendation.
## Objectives

## Materials
Prepared wallet information in print or digital form. Internet access is optional for checking current local information.
## Preparation

## Procedure
### Setup

### Step 1
Review the prepared Bitcoin and Lightning information resources and identify when each source was last checked.
### Step 2
Research or compare wallet options using custody, recovery, payment compatibility, privacy, cost, maintenance, safe support, and whether the software is open source and publicly inspectable.
### Step 3
Choose a wallet for a fictional or stated beginner need and explain the trade-offs. Prefer a well-established open-source option where appropriate, but do not treat open source as proof of safety or suitability and do not name one wallet as best for everyone.
## Review
### Key Points

### Discussion questions
Which wallet best fits the stated need, what trade-offs remain, and what would need to be verified before real use?
## Notes

**Diploma assessment link:** May provide the individual-response context for [`T3` / `C6`](https://programs.myfirstbitcoin.org/programs/educator-guide/). Use the approved protocol; do not ask a learner to choose a real service, use personal funds, or disclose private information. The educator should help learners navigate the decision path without turning a local example into a My First Bitcoin recommendation.
