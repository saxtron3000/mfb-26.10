# Bitcoin Diploma Advanced modules

This directory contains [Advanced modules](https://curriculum.myfirstbitcoin.org/programs/advanced-modules/) being prepared for a post-launch release in November–December 2026. They are works in progress until each module is individually approved and released.

They are not part of the 2026.10 beginner Bitcoin Diploma. The current Bitcoin Diploma is complete through the Student Guide, Educator Guide, Assessment Grid, and Lexicon Entries in `publish/mfb-bd-26.10/`.
