| BD-LEX-030 | **Bitcoin service** | A separate business or tool that uses the Bitcoin network. |
| BD-LEX-031 | **Bitcoin wallet** | A tool that manages keys and helps receive, authorize, and track Bitcoin transactions; it does not literally contain bitcoin. |
| BD-LEX-032 | **Bitcoin whitepaper** | The original paper, Bitcoin: A Peer-to-Peer Electronic Cash System, which described Bitcoin’s design and purpose. |
| BD-LEX-033 | **BitTorrent** | A file-sharing system that demonstrated decentralized information sharing. |

| BD-LEX-040 | **Block-explorer privacy** | The privacy implications of using a public tool to inspect addresses or transactions. |

| BD-LEX-045 | **“By decree”** | By an official order from an authority. |
