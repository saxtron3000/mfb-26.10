# Bitcoin Diploma educator assessment grid

## Purpose

Use one copy of this grid for each learner to record whether they have met every required 2026.10 Diploma objective. It translates the objectives into concise, observable evidence checks; it does not replace the selected assessment task or rubric.

This grid supports the two required, non-compensatory assessment components:

| Component | What the educator records | Completion condition |
| --- | --- | --- |
| Theoretical assessment (50%) | Criteria-based individual evidence from learner explanations, comparisons, illustrations, discussions, or scenarios. | Every required theory row is **Meets standard**. |
| Practical competency assessment (50%) | Direct educator observation of the required Module 3 and selected Module 4 performance. | Every required practical row is **Meets standard**. |

A result in one component cannot compensate for an unmet result in the other. Optional app activity, attendance, confidence, participation, or learner self-report is not formal assessment evidence.

## Learner record

| Learner | Cohort / delivery mode | Educator | Assessment dates |
| --- | --- | --- | --- |
|  |  |  |  |

**Result key:** `MS` = Meets standard; `NY` = Not yet; `—` = not assessed yet. Record the task or interaction ID, date, and a short evidence reference in the final column. Keep records private; never record seed phrases, private keys, credentials, balances, or unnecessary personal information.

## How to use the grid

1. Before assessment, identify the task or educator interaction, permitted prompting, accessibility accommodation, and safety stop conditions for each row.
2. Give the learner supported practice before collecting formal evidence.
3. Mark `MS` only when the learner produces the listed evidence with the stated level of support. Mark `NY` when the evidence is incomplete, inaccurate, unsafe, or overly prompted.
4. Give focused feedback and reassess any `NY` objective using the same standard. Do not average a safety-critical error away.
5. Mark the learner **assessment-complete** only after every required row in both components is `MS` and the required evidence is recorded.

`ALL.1` and `ALL.2` remain formative under the current objectives and are not included as certification rows.

## Use the grid with the task rubric

The grid is an educator record, not a substitute for the task rubric. Use the task instructions and rubric to determine permitted prompting, detailed performance criteria, safety-critical errors, feedback, and reassessment. Do not use a local adaptation to waive, weaken, or redefine a required objective.
