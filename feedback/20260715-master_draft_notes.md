2. **Page mapping:** Some later annotations differ by one or two pages between drafts, notably circular-economy review ownership and Block 3/4 transitions. Use the PDF page image, not either derived page number, as final authority.
3. **Core/Custom/Advanced:** Both see terminology problems. Codex recommends Blocks 1–3 as Core and Block 4 as optional/local; Claude additionally suggests removing "Custom" from the learner-facing Diploma entirely.
4. **Bitcoin-only wording:** Claude calls for an explicit Bitcoin-only statement near the disclaimer. Codex is more cautious about absolute or promotional framing. The final edit should state scope clearly without turning it into an unsupported claim.
5. **Money history:** Claude retains the idea that monetary evolution reflects civilizational progress. Codex warns against implying a universal linear history. If retained, present it as a discussion prompt or viewpoint, not settled fact.
6. **Advanced material:** Both recommend moving complexity out of Core, but Codex identifies many more candidates, including banking mechanics, proof-of-work depth, routing/channels, recovery variants, and technical/API material.
