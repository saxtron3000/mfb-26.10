This lexicon lists Bitcoin and Bitcoin-adjacent terms that an educator may need to explain. It is the terminology authority for the Educator Guide. Each listed term has a stable anchor for links from that guide.

Link a term only when it is used in a Bitcoin, economic, or computing sense and the linked definition explains that specific use. Leave ordinary English uses and incidental word matches unlinked; use the more specific entry when one exists, such as Lightning liquidity for channel capacity.

For **privacy**, link only uses where the word is a noun in its own right (for example, `protect privacy` or `financial privacy`). Do not link attributive uses that modify another noun, including shared modifiers in lists (for example, `privacy risks` or `privacy and safety boundaries`).

This table lists each verified linked-use line in the current [Educator Guide](https://programs.myfirstbitcoin.org/programs/bitcoin-diploma/en/educator-guide/). Its line number opens the containing section. Only terms with at least one linked-use line are listed. Ordinary uses with a different meaning are excluded.

Guide traceability was refreshed on 8 October 2026 from the published Educator Guide. Run `python3 tools/refresh_lexicon.py --check` after guide edits to audit the snapshot and linked-use metadata.
