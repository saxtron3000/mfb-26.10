# October 2026 Review Scope

## File Contract

**Role:** This file is the boundary document for the October 2026 review pass.

**Purpose:** Define what is in scope, what is out of scope, and which program-level questions need attention during this refresh.

**Structure:** Keep the scope organized as goal, core review areas, lesson and activity edits, program design questions, supporting materials, follow-up, and out-of-scope items.

**Use this file for:** Deciding whether proposed work belongs in the October 2026 review cycle and keeping the refresh from expanding without intention.

**Do not use this file for:** Detailed task status, raw feedback, curriculum drafts, or stable program overview prose.

**Contributor update rule:** Use this file as a decision boundary. If scope language creates an actionable item, track that item in `03_tasks.md` instead of turning this file into a checklist.

This document outlines the review and edit scope for the October 2026 version of *Bitcoin for Juniors*.

Source: `ref/ED-DEV.csv`

## Goal

Review the current *Bitcoin for Juniors* program and prepare a stronger October 2026 version that is clearer, more practical, easier to teach, and more engaging for students.

## Core Review Areas

- Review the full program for clarity, flow, and age fit.
- Make the lesson structure more concise where sections repeat or overlap.
- Check that each activity has clear objectives, timing, materials, and facilitator guidance.
- Strengthen student-facing language so objectives and tasks are easier for children to understand.
- Add more practical, low-prep classroom options, including sponge activities and differentiation.
- Add pedagogical and Bitcoin-related references where they support the lesson design.

## Lesson And Activity Edits

- Review `Money Matters` and decide whether it needs a more robust version.
- Fine-tune `Money Matters`.
- Check the timing of Lesson 1.1 `Ship Rekt` and confirm that the tasks fit the total lesson time.
- Decide whether Lesson 1.1 should move to Lesson 1.3.
- Apply the definitive activity structure in `06_template.md` across every Bitcoin for Juniors activity.
- Design the Chapter 4 trust activity.
- Review ROOT's barter activity for useful ideas.

## Program Design Questions

- Decide whether rewards should use a low-tech approach for version 2, such as Lightning Piggy, Bolt Cards, or another simple classroom system.
- Explore whether a `My Stack` Lightning Network gamification layer belongs in the program.
- Research identity formation and groupthink where these ideas affect lesson design.
- Review automated feedback for interactivity, tone, fun, effectiveness, and readability.
- Improve differentiation so tasks can support split-level and cooperative learning.

## Supporting Materials

- Review the parent guide.
- Write or revise forewords for each chapter.
- Create a design brief for *Bitcoin for Teens* where it connects to the B4J pathway.
- Start a one-pager explaining the Bitcoin mindset to teachers who are new to Bitcoin.
- Review domain and web options related to `bitcoinforjuniors`.

## Follow-Up

- Follow up with Pedro Amantikir.
- Review the comment in the *Bitcoin for Juniors Program - MFB* document.
- Explore whether *Bitcoin for Juniors* could be taught in another country.
- Plan any relevant outreach connected to the Crypto Latam conference.

## Out Of Scope For This Pass

- Building a full new program from scratch.
- Finalizing the *Bitcoin for Teens* program.
- Creating a full web product or reward platform unless the review confirms it is needed.
