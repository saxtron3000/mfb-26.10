# Bitcoin Diploma Learning Objectives

## Purpose

This document defines realistic learning objectives for the redesigned Bitcoin Diploma.

It answers:

- what every learner should be able to explain after the Core Diploma;
- what learners may practice in a local Custom block;
- what belongs outside the 8-hour beginner pathway;
- how objectives connect to the 4-block structure.

This document does not define activities, assessment methods, certification requirements, or project milestones.

---

# 1. Status

These objectives are a working framework.

Planning rule:

If an objective cannot be taught, practiced, and assessed inside the 8-hour scope, it is not a Core objective.

Advanced objectives are ongoing and should be designed module by module after the Core Diploma is stable.

---

# 2. Graduate Profile

A realistic graduate of the 8-hour beginner Diploma can:

| Area | Realistic outcome |
|---|---|
| Knowledge | Understands beginner money, fiat, Bitcoin, wallet, custody, and safety concepts. |
| Explanation | Can explain core ideas in plain language. |
| Comparison | Can compare fiat money and Bitcoin at beginner level. |
| Practical orientation | Can identify wallet types, custody trade-offs, and safe next steps. |
| Reasoning | Can participate in guided discussion using simple evidence and trade-off thinking. |
| Confidence | Can ask better questions, avoid obvious beginner mistakes, and continue learning. |

The Diploma should not claim that every graduate can independently manage high-stakes custody, perform advanced technical troubleshooting, or master economic, technical, or philosophical analysis.

---

# 3. Objective Levels

## Core Outcomes

Core outcomes are required for every learner.

Every learner should be able to:

1. Explain what money is and why societies use it.
2. Identify the functions and properties of money.
3. Describe basic fiat-system problems, including inflation and purchasing power loss.
4. Explain why Bitcoin was created at beginner level.
5. Identify Bitcoin's core properties: decentralization, finite supply, peer-to-peer transfer, and verifiability.
6. Describe users, nodes, miners, proof of work, the 21 million limit, and halving at beginner level.
7. Explain wallets, keys, seed phrases, and custody at beginner level.
8. Compare custodial and non-custodial approaches at beginner level.
9. Identify basic safety practices and common beginner risks.
10. Describe receiving, sending, and verification at beginner level.
11. Distinguish beginner practical Bitcoin use from advanced technical theory.
12. Participate in guided discussion using clear explanations and basic reasoning.

## Custom Outcomes

Custom outcomes are selected by educators for Block 4: Custom / Bitcoin as Money.

Custom outcomes should connect Bitcoin to local daily life through practical workshops, demonstrations, local tools, and community-specific examples.

Depending on local context, learners may:

- discuss local Bitcoin use cases;
- compare local money tools and trade-offs;
- explore circular economies;
- complete app-specific wallet demonstrations;
- practice local payment scenarios;
- identify resources used by local bitcoiners;
- connect Bitcoin concepts to local economic conditions;
- identify realistic next steps for their community.

Custom outcomes are required only when they are added to a local delivery plan.

## Advanced Outcomes

Advanced outcomes do not belong in the Core 8-hour Diploma.

Status: ongoing.

They should be designed module by module. The candidate Advanced module titles are maintained in `07_plan.md` and should not become Core objectives.

# 4. Block-To-Objective Map

| Block | Learner promise | Objective emphasis |
|---|---|---|
| Problem / Fiat | Learners understand the money problem Bitcoin responds to. | Define money, identify functions and properties, explain beginner fiat weaknesses. |
| Solution / Bitcoin | Learners understand why Bitcoin was created and what makes it different. | Explain Bitcoin's purpose, fixed supply, peer-to-peer transfer, decentralization, and verification. |
| Action / Self-custody | Learners understand what responsibility looks like in practice. | Explain wallets, keys, seed phrases, custody trade-offs, receiving, sending, verification, and safety. |
| Custom / Bitcoin as Money | Learners see how Bitcoin can function as money locally. | Educator-selected outcomes using local tools, workshops, demonstrations, and case examples. |

This map should guide assessment, Activity Bank design, Educator Guide pacing, and public communication.

---

# 5. Competency Areas

| Competency | Learners can... |
|---|---|
| Monetary foundations | Explain what money is, why it exists, and what makes money useful. |
| Beginner economic reasoning | Use scarcity, time preference, opportunity cost, incentives, and trade-offs in simple discussions. |
| Bitcoin fundamentals | Explain Bitcoin's purpose, core properties, and role as monetary technology. |
| Practical Bitcoin orientation | Identify beginner actions, safety practices, wallet concepts, and custody trade-offs. |
| Guided critical discussion | Discuss simple Bitcoin claims using prompts, evidence, and clear reasoning. |
| Social learning | Listen, ask clarifying questions, explain their thinking, and participate respectfully. |
| Local relevance | Reflect on how Bitcoin may relate to local community conditions when included in delivery. |

# 6. Bloom's Taxonomy Scope

The Core Diploma should focus on:

- Remember: define key concepts.
- Understand: explain functions, systems, and relationships.
- Apply: use concepts in guided scenarios.

The Core Diploma may introduce:

- Analyze: compare simple trade-offs with educator support.
- Evaluate: assess simple claims using guided prompts.

Create-level tasks belong in Custom or Advanced material unless a local module explicitly includes them.

---

# 7. Objective Template

Each block should define:

- core idea;
- core question;
- required Core objectives;
- optional Custom objectives, if relevant;
- Advanced or out-of-scope boundaries;
- practical orientation;
- discussion competence;
- review point.

Use this wording pattern:

Learners should be able to `[measurable verb]` `[beginner-appropriate concept or action]` `[condition or support level]`.

Example:

Learners should be able to explain the difference between custodial and non-custodial wallets using beginner language and guided examples.

# 8. Gaps To Resolve
