# Required Redesign Visuals

## 4-Block Diagram

Purpose: explain the core architecture quickly.

Must show:

1. Problem / Fiat
2. Solution / Bitcoin
3. Action / Self-custody
4. Custom / Bitcoin as Money

## Before / After Visual

Purpose: show why the redesign matters.

Must compare:

- long and dense pathway to 8-hour pathway;
- embedded activities to Activity Bank;
- mixed beginner and advanced content to Core / Custom / Advanced separation;
- unclear local adaptation to educator-selected Custom block.

## Learning Ecosystem Diagram

Purpose: show that the Diploma is not only one document.

Must include:

- Student Book;
- Educator Guide;
- Activity Bank;
- Custom Module Bank;
- Advanced pathways.

## Educator Choice Diagram

Purpose: explain Block 4.

Must show:

- shared blocks;
- educator-selected Custom / Bitcoin as Money block;
- local tools, needs, risks, and opportunities.

## Pathway Diagram

Purpose: distinguish beginner Diploma from follow-on learning.

Must show:

- Core Diploma;
- Custom modules;
- Advanced pathways;
- future certification questions separated from current redesign.
