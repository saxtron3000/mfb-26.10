# Required Redesign Visuals

## 4-Block Diagram

Purpose: explain the core architecture quickly.

Must show:

1. Problem / Fiat
2. Solution / Bitcoin
3. Action / Self-custody
4. Custom / Bitcoin as Money

## Before / After Visual

Purpose: show why the redesign matters.

Must compare:

- long and dense pathway to 8-hour pathway;
- embedded activities to Activity Bank;
- mixed beginner and advanced content to Core / Custom / Advanced separation;
- unclear local adaptation to educator-selected Custom block.

## Learning Ecosystem Diagram

Purpose: show that the Diploma is not only one document.

Must include:

- Student Book;
- Educator Guide;
- Activity Bank;
- Custom Module Bank;
- Advanced pathways.

## Delivery-Mode Branch Diagram

Purpose: show the first delivery mode and future branches without implying separate curricula.

Must show:

- offline/in-person print or PDF first;
- online PDF;
- online cohort;
- self-paced;
- web;
- future app;
- eventual cross-modal continuation;
- shared Core outcomes across all branches.

## Educator Choice Diagram

Purpose: explain Block 4.

Must show:

- shared blocks;
- educator-selected Custom / Bitcoin as Money block;
- local tools, needs, risks, and opportunities.

## QR Code Placement Plan

Purpose: prevent print clutter and stale destinations.

Must identify only stable, high-value QR destinations, such as:

- source or update page;
- educator resources;
- support or donation page;
- certificate verification, if available.

Avoid using many QR codes inside the main learner path.

## Pathway Diagram

Purpose: distinguish beginner Diploma from follow-on learning.

Must show:

- Core Diploma;
- Custom modules;
- Advanced pathways;
- future certification questions separated from current redesign.

# Prague Keynote Asset Needs

The 10-minute keynote needs:

- title slide visual;
- 4-block diagram;
- before / after table;
- delivery-mode branch diagram;
- Activity Bank and Educator Guide ecosystem diagram;
- public call-to-action slide.

Do not include the full Advanced module title list in Prague slides.

Visuals should remain legible after translation. Avoid embedding long English phrases directly into diagrams when labels can be managed in source files.
