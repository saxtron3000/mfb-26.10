# Review run records

Create one dated record for every style or alignment review. Copy [template.md](template.md) to `YYYY-MM-DD-<mode>-<scope>.md`, using `change`, `targeted`, or `full-release` as the mode. Examples: `2026-09-21-change-student-guide-links.md` and `2026-10-01-full-release-26.10.md`.

Run records are evidence of a review, not sources of truth. The `workspace/` documents remain authoritative. Keep a run record even when no finding is created, and link every created or updated `ACT-`, `EVO-`, or `PUB-` item to it.
