# Package Purpose

This package documents the redesign of the Bitcoin Diploma.

The objective is to improve:

- completion rates;
- educational impact;
- practical competence;
- educator usability;
- consistency of delivery;
- scalability;
- long-term relevance;

while preserving the identity, philosophy, seriousness, and community-driven nature of the Diploma.

---

# Applied Design Direction

The following decisions are now considered part of the working redesign direction:

- Maximum target duration: 8 hours.
- Working architecture: 4 modules of approximately 2 hours.
- In-person first.
- Single Diploma with optional advanced sections.
- Emerging content structure:
  - Core
  - Nice-to-Have
  - Advanced
- Certification design deferred until learning outcomes are finalized.
- Learning objectives should include:
  - Knowledge objectives
  - Competency objectives
  - Outcome objectives
- Practical learning should increase from approximately 20% toward approximately 40%.
- Practical skills should use PPP:
  - Presentation
  - Practice
  - Production
- Advanced technical content should move to optional advanced sections.
- Educator Guide should become an essential implementation tool.
- Activity Bank should be both embedded and standalone.
- Localization should be considered during design but largely implemented after launch.
- AI may adapt content but should not modify learning objectives.

# Consolidation Rules

1. Decisions should be evidence-driven whenever possible.
2. Learning outcomes drive assessment.
3. Assessment drives certification.
4. Certification should not drive curriculum design.
5. Essential content should be distinguished from advanced content.
6. Educator needs are considered alongside learner needs.
7. Localization should adapt content, not structure.
8. Learning objectives remain standardized.
9. Open-source publication remains a core requirement.
10. Community adaptability should not weaken standards.
