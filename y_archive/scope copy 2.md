# Additional Scope Items

## 11. Competency Mapping System

### Purpose

Create explicit links between:

- learning objectives
- competencies
- activities
- assessments
- learner outcomes

### Deliverables

- Competency framework
- Competency-to-module map
- Competency-to-activity map
- Competency evidence framework

### Success Criteria

- Every competency linked to learning activities
- Every competency linked to observable evidence
- Progression visible across the Diploma

---

## 12. Scope Rationalization & Content Reduction

### Purpose

Reduce cognitive load and remove unnecessary learning requirements.

### Deliverables

- Content audit
- Duplicate content audit
- Content reduction recommendations
- Essential vs Optional content classification
- Beginner prerequisite analysis

### Success Criteria

- Reduced repetition
- Reduced cognitive load
- Clear prioritization of content

---

## 13. Delivery Model Definition

### Purpose

Clarify implementation expectations.

### Deliverables

- In-person delivery specification
- Online adaptation guidance
- Self-paced adaptation guidance
- Delivery assumptions documentation

### Success Criteria

- Clear primary delivery model
- Reduced interpretation differences between educators

---

## 14. Timing & Workload Validation

### Purpose

Ensure realistic implementation.

### Deliverables

- Module timing analysis
- Activity timing analysis
- Total workload analysis
- Facilitator implementation guidance

### Success Criteria

- Timing assumptions documented
- Activities included in timing estimates
- Realistic delivery expectations

---

## 15. Measurable Outcomes Framework

### Purpose

Improve the ability to evaluate learning impact.

### Deliverables

- Outcome framework
- Outcome indicators
- Learning evidence recommendations
- Program impact indicators

### Success Criteria

- Outcomes measurable
- Outcomes aligned with objectives
- Outcomes aligned with competencies

---

## Additional Definition of Completion

The redesign is complete when:

- Competencies are mapped to modules
- Competencies are mapped to activities
- Competencies are mapped to evidence
- Essential and optional content are clearly separated
- Timing assumptions are documented
- Delivery assumptions are documented
- Measurable outcomes are defined
