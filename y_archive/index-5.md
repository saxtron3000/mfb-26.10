# Bitcoin Diploma Redesign Documentation Index

## Purpose

This folder contains the planning, research, review, design, and implementation documents for the Bitcoin Diploma redesign.

The documents are intentionally separated so that:

- Review remains independent from Design.
- Design remains independent from Scope.
- Scope remains independent from Learning Objectives.
- Research remains independent from conclusions.

This separation helps prevent assumptions, circular reasoning, and premature design decisions.

The package should be read as a decision-making system rather than a collection of isolated documents.

---

# Recommended Reading Order

For a new contributor, researcher, curriculum designer, educator, consultant, or AI agent:

1. review.md
2. research.md
3. design.md
4. objectives.md
5. scope.md

This sequence follows the intended workflow:

Current State → Evidence → Design → Outcomes → Implementation

# Core Principles

The redesign is based on the following principles:

1. Evidence before opinion.
2. Outcomes before content.
3. Assessment follows outcomes.
4. Certification follows assessment.
5. Design before implementation.
6. Educator needs matter.
7. Learner needs matter.
8. Community adaptability matters.
9. Standards matter.
10. Open-source publication matters.

---

# Current Working Direction

The following decisions have been provisionally accepted:

- In-person first.
- Maximum target duration approximately 8 hours.
- Modular structure under exploration.
- Single Diploma with optional advanced pathways.
- Increased practical learning.
- PPP methodology for practical skills.
- Educator Guide as a facilitation engine.
- Activity Bank as a core ecosystem component.
- Learning objectives remain standardized.
- Localization occurs primarily through examples, activities, and facilitation.

These decisions should still be evaluated against research and learning outcomes as work progresses.
